# @m3-expressive/styles

Framework-agnostic Material 3 Expressive CSS tokens, color schemes, spring transitions, and component styles.

## Installation

```bash
npm install @m3-expressive/styles
```

## Usage

```css
/* In your CSS entry point */
@import "@m3-expressive/styles";
@import "@m3-expressive/styles/fonts.css";
```

Or in JS/TS:

```js
import '@m3-expressive/styles'
import '@m3-expressive/styles/fonts.css'
```
