# @m3-expressive/core

Framework-agnostic Material 3 Expressive dynamic color calculations, spring motion physics, shape morphing, and DOM theme utilities.

## Installation

```bash
npm install @m3-expressive/core
```

## Features

- **Dynamic Color**: HCT color space scheme generators, tonal palettes, and CSS declarations.
- **Spring Motion**: Damped-spring solver, physics constants for spatial & effects springs, CSS `linear()` conversions.
- **Shapes & Morphing**: 35 Material shapes, SVG paths, polygon resampling, smooth outline morphing.
- **Theme Init Script**: Zero-flash inline theme loader for SSR.
- **Ripple DOM Engine**: Framework-agnostic ripple and state layer attachment.
